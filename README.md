# Alvora Tech HQ (`alvoratechhq.com`)

> High-performance digital engineering, local search authority, and customer conversion platforms for modern local businesses. Built with Linear & Apple-grade aesthetic precision.

---

## 💎 Design & Architecture Philosophy

- **Linear & Apple Notes Craftsmanship:** Minimalist obsidian canvas (`#08090D`), radiant indigo/cyan accent gradients, micro-borders (`border-white/[0.08]`), and zero superfluous marketing fluff.
- **Townsquare Interactive Inspiration:** High-conversion web engineering, local Google 3-Pack rank, 50+ directory sync (Google, Apple Maps, Yelp, Bing), automated lead SMS/WhatsApp routing, and zero-touch maintenance.
- **Performance First:** 99/100 Core Web Vitals, sub-second Time to Interactive (<0.6s), responsive across mobile, tablet, and ultra-wide screens.

---

## 🚀 Key Modules & Interactive Features

1. **Precision Vector Logo Component (`src/components/Logo.jsx`)**: Custom geometric dual-apex prism combining 'A' and 'V' with prismatic lighting.
2. **Interactive Niche Demo Hub (`src/components/LiveDemoShowcase.jsx`)**:
   - 🔧 Trade Contractors (Plumbing, HVAC, Electrical)
   - 👗 Retail & Boutique (Luxury Apparel, Jewelry)
   - ✨ Clinical Aesthetics & Wellness (MedSpa, Dermatology)
   - 🍽️ Hospitality & Dining (Fast QR Menus, Table Reservations)
   - In-app modal with Desktop/Mobile simulation view and instant lead dispatch testing.
3. **Interactive ROI Growth Simulator (`src/components/RoiCalculator.jsx`)**: Sliders for monthly inquiries and average job value calculating projected annual revenue gains.
4. **Performance Engine Teardown (`src/components/GrowthEngine.jsx`)**: Direct, high-contrast teardown comparing outdated local websites vs Alvora Tech's modern architecture.
5. **Transparent Pricing (`src/components/Pricing.jsx`)**: Linear-style switcher between Monthly Growth Partner ($149, $299, $549/mo) and Turnkey Upfront Builds ($799, $1,499, $2,799).
6. **Interactive Proposal & Blueprint Modal (`src/components/ProjectModal.jsx`)**: Interactive multi-step inquiry generator with instant confirmation state.

## 🛠️ Tech Stack

- **Framework:** React 18, Vite 6
- **Styling:** Tailwind CSS, PostCSS, Autoprefixer
- **Icons:** React Icons (`react-icons/fi`, `react-icons/ri`, `react-icons/si`)
- **Typography:** Plus Jakarta Sans & JetBrains Mono (Google Fonts)
- **Deployment:** Vercel Edge Ready (`vercel.json`)
